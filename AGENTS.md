# CAM Sports publishing

This repository will publish the free address https://camsports.github.io/.
Keep it public and use only free GitHub Pages and public GitHub-hosted runners.
Do not add payment details, paid runners, credentials, or secrets.

The canonical application remains in
https://github.com/eduardcarrera00-pixel/RCM-Sports.
Do not copy or independently edit the application here. The workflow publishes
the current source main branch, preserving its design and database configuration.

After a source change, update `.github/source-revision-request.txt` with the
current full source main SHA and a newline to request immediate publication.
Verify the workflow and public `source-revision.txt` before reporting completion.
Scheduled publication runs every five minutes, subject to GitHub delays and
inactivity rules.
