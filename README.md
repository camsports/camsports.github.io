# CAM Sports

Free GitHub Pages publisher for https://camsports.github.io/.

The application source is maintained in
[eduardcarrera00-pixel/RCM-Sports](https://github.com/eduardcarrera00-pixel/RCM-Sports).
This repository contains publication configuration only. It uses the existing
application and data, with no paid domain or paid hosting.

GitHub Pages must use **GitHub Actions** as its publishing source. Pushes here,
manual workflow runs, and the scheduled workflow publish the latest source main
branch. Unchanged scheduled runs skip deployment.
